# ระบบติดตามสำนวนคดีสืบสวน บก.ปอท. (TCSD Case Intelligence & To-Do Tracker)
### กองบังคับการปราบปรามการกระทำความผิดเกี่ยวกับอาชญากรรมทางเทคโนโลยี (บก.ปอท.)
### กองบัญชาการตำรวจสอบสวนกลาง (CIB - Central Investigation Bureau)

ระบบบริหารจัดการและติดตามสำนวนคดีสืบสวน (Case To-Do & Tracking System) ออกแบบสำหรับชุดสืบสวน บก.ปอท. โดยเฉพาะ ให้สามารถติดตามความคืบหน้าของงานคดีแบบ Real-time, ตรวจสอบสถานะการขอข้อมูลจากหน่วยงานภายนอก (ธนาคาร, ค่ายมือถือ, แพลตฟอร์มโซเชียลมีเดีย), กำกับดูแล Deadline วันครบกำหนดส่ง และส่งออกรายงานสรุปเสนอผู้บังคับบัญชาได้อย่างรวดเร็ว

---

## 🌟 ฟังก์ชันหลักของระบบ (Key Features)

### 1. ธีมและ CI สไตล์ตำรวจสอบสวนกลาง (CIB High-Tech Cyber Theme)
- โทนสีหลัก: กรมท่า/น้ำเงินเข้ม CIB (`#070D1E`, `#0B142B`), ตัดด้วยสีเหลืองทอง CIB (`#F59E0B`, `#FBBF24`), และแสงนีออน Cyan/Blue สไตล์งานสืบสวนอาชญากรรมทางเทคโนโลยี
- แสดงตราสัญลักษณ์ **TCSD Logo** (บก.ปอท.) ที่หัวระบบ หน้าเข้าสู่ระบบ และรายงานอย่างสง่างาม
- ดีไซน์การ์ดและตารางแบบ Futuristic Cyber HUD พร้อมเอฟเฟกต์ Glassmorphism และระบบแจ้งเตือนสีตามความเร่งด่วน

### 2. มุมมองหัวหน้าทีม (Leader View / ศูนย์บัญชาการคดี)
- **Executive Dashboard:** สรุปภาพรวมคดีทั้งหมดในระบบ, คดีที่กำลังสืบสวน, คดีที่รอผลจากหน่วยงานภายนอก, คดีเกินกำหนด (Overdue Alert) และคดีที่ตรวจเสร็จสมบูรณ์
- **3-Step Verification Pipeline:** กราฟสรุปความคืบหน้าขั้นตอนการสืบสวน 3 ขั้นตอนของทั้งทีม (ขอข้อมูลแล้ว ➔ ได้รับแล้ว ➔ ตรวจสอบข้อมูลแล้ว)
- **Investigator Workload Matrix:** แสดงภาระงานของเจ้าหน้าที่แต่ละนาย (ใครถืองานกี่คดี เสร็จกี่คดี มีคดีเกินกำหนดหรือไม่) พร้อมคลิกที่ชื่อเพื่อกรองดูเฉพาะงานของบุคคลนั้นได้ทันที
- **Target Agency Breakdown:** สรุปรายการหน่วยงานปลายทางที่อยู่ระหว่างรอข้อมูล (เช่น ธนาคารกสิกรไทย, AIS, True, ปปง., Bitkub ฯลฯ)
- **Commander Export Report:** ปุ่มส่งออกรายงานสำนวนคดีเป็น **Excel (.xlsx)** สรุปเสนอผู้บังคับบัญชา จัดระเบียบหัวตารางและคอลัมน์มาตรฐานตำรวจอย่างสวยงาม

### 3. มุมมองทีมงาน (Member View / หน้างานของฉัน & สรุปภาพรวม)
- **งานที่ฉันรับผิดชอบ (My Assigned Tasks):** เจ้าหน้าที่สามารถโฟกัสงานของตนเอง ตรวจสอบรายการคดีที่ได้รับมอบหมาย และอัปเดตสถานะได้สะดวกรวดเร็ว
- **Dashboard รวมของทีม (Team Overview):** ทีมงานสามารถสลับแท็บเพื่อดูสถิติภาพรวมของทีมได้ตลอดเวลาตามที่กำหนด
- **งานทั้งหมดของทีม (All Team Tasks):** สามารถเปิดดูงานของเพื่อนร่วมทีมเพื่อการประสานงานและช่วยเหลืองานกันในชุดสืบสวน
- ติ๊กเครื่องหมาย 3 ช่องได้ในคลิกเดียว พร้อมเอฟเฟกต์เฉลิมฉลองเมื่อตรวจสอบหลักฐานครบ 100%

### 4. ระบบข้อมูลคดีสืบสวนและช่องติ๊กถูก 3 ช่อง (Core Task Fields)
ในแต่ละงานคดีบรรจุข้อมูลครบถ้วนตามมาตรฐานงานสืบสวน:
1. **ชื่องาน / คดีสืบสวน:** (เช่น สืบสวนเครือข่ายแก๊งคอลเซ็นเตอร์, คดีหลอกลงทุนคริปโต ฯลฯ)
2. **เลขที่หนังสือราชการ:** (เช่น ตช 0026.3/1429)
3. **รายละเอียดพฤติการณ์ / ประเด็นสืบสวน:** ข้อมูลผู้เสียหาย บัญชีเป้าหมาย หรือประเด็นที่ต้องแกะรอย
4. **วันที่ทำ / วันที่เริ่มสืบสวน**
5. **วันครบกำหนด (Deadline):** ระบบคำนวณและแสดง Badge นับถอยหลังอัตโนมัติ (เช่น *เหลือ 2 วัน (เร่งด่วน)*, *เกินกำหนด 1 วัน (OVERDUE)* พร้อมแถบเตือนสีแดงกระพริบ)
6. **สถานะ:** รอดำเนินการ, กำลังสืบสวน, รอผลหน่วยงาน, เสร็จสิ้นสมบูรณ์
7. **กล่อง Checkbox 3 ช่องสำหรับการติดตามข้อมูล (1-Click Toggle):**
   - ☑️ **1. ขอข้อมูลแล้ว:** ส่งหนังสือราชการไปยังหน่วยงานที่เกี่ยวข้อง
   - ☑️ **2. ได้รับแล้ว:** ได้รับเอกสาร สเตตเมนต์ หรือบันทึกจราจรทางคอมพิวเตอร์ (Log)
   - ☑️ **3. ตรวจสอบข้อมูลแล้ว:** วิเคราะห์เส้นทางการเงิน/หลักฐานดิจิทัลเรียบร้อย
8. **หน่วยงานปลายทางที่ขอข้อมูล:** มีระบบชิปทางลัดคลิกเลือกด่วน (KBANK, SCB, KTB, BBL, AIS, True, Meta, Bitkub, ปปง., DBD ฯลฯ)
9. **หมายเหตุ (Notes)**
10. **ระบบประวัติและไทม์ไลน์ (Audit Log):** บันทึกประวัติอัตโนมัติว่าใครเป็นผู้ติ๊กช่องไหน เวลาใด พร้อมช่องพิมพ์บันทึกความคืบหน้าเพิ่มเติม

### 5. ระบบความปลอดภัยและการเข้าสู่ระบบ (Authentication)
- รองรับการล็อกอินด้วย Username & Password
- มีปุ่ม **Quick Demo Login** ให้เข้าใช้งานทดสอบได้ใน 1 คลิก ทั้งในบทบาทหัวหน้าทีมและเจ้าหน้าที่สืบสวน
- บัญชีเริ่มต้นในระบบ:
  - 👮‍♂️ **หัวหน้าทีม (ผกก.กิตติพงษ์):** `username: leader` | `password: password123`
  - 🕵️‍♂️ **เจ้าหน้าที่สืบสวน 1 (ร.ต.อ. สมชาย):** `username: somchai` | `password: password123`
  - 👨‍💻 **เจ้าหน้าที่สืบสวน 2 (ร.ต.ท. ธนกร):** `username: thanakorn` | `password: password123`
  - 👩‍💻 **เจ้าหน้าที่สืบสวน 3 (ร.ต.อ.หญิง อัญชลี):** `username: anchalee` | `password: password123`

### 6. การเชื่อมต่อ Cloud & การแชร์ในเครือข่าย LAN
- **โหมดใช้งานร่วมกันในทีม (LAN/Intranet):** รันเซิร์ฟเวอร์กลางที่เครื่องแม่ข่าย แล้วสมาชิกในทีมเปิดผ่านบราวเซอร์เครื่องตนเองได้พร้อมกันทันที
- **โหมด Cloud Ready:** รองรับการเชื่อมต่อกับ Firebase, Supabase หรือ Cloud REST API ผ่านหน้าตั้งค่า
- **ระบบสำรองข้อมูล (Backup & Restore):** ดาวน์โหลดฐานข้อมูลเป็นไฟล์ JSON สำรองไว้ หรือกู้คืนข้อมูลได้ตลอดเวลา

## 🚀 วิธีการเปิดใช้งานระบบ (Quick Start)

### วิธีที่ 1: รันระบบเซิร์ฟเวอร์แบบ Production (แนะนำสำหรับการใช้งานจริงในทีม)
1. ดับเบิลคลิกที่ไฟล์ **`start-server.bat`** (หรือพิมพ์คำสั่ง `node server.js` ใน Terminal)
2. เปิดเว็บเบราว์เซอร์ (Chrome / Edge / Firefox) แล้วไปที่:
   ```
   http://localhost:5000
   ```
3. หากต้องการให้เพื่อนร่วมทีมในวง WiFi / LAN เดียวกันเข้าใช้งาน ให้แจ้ง URL ด้วยหมายเลข IP เครื่องแม่ข่าย เช่น:
   ```
   http://192.168.1.XXX:5000
   ```

### วิธีที่ 2: รันโหมดพัฒนา (Development Mode with Vite)
1. ดับเบิลคลิกที่ไฟล์ **`start-dev.bat`** (หรือพิมพ์คำสั่ง `npm run dev`)
2. เปิดเบราว์เซอร์ไปที่:
   ```
   http://localhost:5173
   ```
